Обновлено ядро CLIProxyAPI с v8.0.63 до v8.0.76. Сохранены строгая маршрутизация по квотам, привязки сессий после перезапуска и usage-observer.

- Патч адаптирован к обновлённому scheduler. Подтверждённые квоты пересчитываются после исключения кандидатов; добавлены проверки single/mixed selection и исчерпания квоты другой сессией во время выбора аккаунта.
- Версия ядра, commit SHA и путь патча записаны в `upstream.json`, который входит в релизные архивы. Обычная сборка проверяет точный SHA upstream.
- CI ежедневно проверяет наличие нового стабильного релиза CLIProxyAPI и его совместимость с текущим патчем, observer и API панели. Обнаружение новой версии не меняет закреплённое ядро автоматически.
- Проверки ядра и интеграции добавлены в CI для pull request и push. Для локальной проверки другой версии доступны `--upstream` и `--output-dir` у `bun run build:core`.

Обновление с v0.3.0: сохраните приватную копию `.env`, `.data` и OAuth-файлов. Остановите старое ядро и панель, замените пакет, затем запустите `proxcli hub` и `proxcli serve`. Сохраняйте `affinity.enc` вместе с `affinity.enc.key`; существующие настройки и привязки используются обновлённым ядром.

В архивах есть панель, подготовленное ядро и native usage-observer для macOS arm64/amd64, Linux arm64/amd64 и Windows amd64. Go/Bun для запуска не нужны. Пакеты не подписаны сертификатом разработчика. Контрольные суммы публикуются в `SHA256SUMS`.

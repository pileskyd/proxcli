Первый публичный релиз ProxCli.

- Локальная тёмная панель Vue 3, OAuth Claude/Codex и отдельный proxy на каждую подписку.
- Окна квот и история расхода/cache reads/cache writes за 30 дней.
- Soonest-reset-first для новых сессий, встроенная affinity и `quota-strict`: активная сессия переносится только при подтверждённом исчерпании квоты.
- Нативные пакеты: macOS arm64/amd64, Linux arm64/amd64 и Windows amd64. Внутри UI, панель, подготовленное ядро CLIProxyAPI v8.0.63 и usage-observer. Bun/Go для запуска не нужны.

Проверяйте архив по SHA-256 из `SHA256SUMS`. Пакеты не подписаны сертификатом разработчика. Инструкция — в README внутри архива и репозитории.

Известные ограничения: affinity теряется при перезапуске ядра; history observer best-effort и сообщает о потерях; неизвестные/устаревшие квоты не подменяются оценками. Реальные OAuth-входы и inference требуют собственных аккаунтов и прокси.
